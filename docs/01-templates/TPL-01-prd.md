# 模板 — 产品需求文档（PRD）

> 用于顶层产品文档。PRD 在产品范围内描述*为什么做*和*做什么*。详细的原子化需求存放于 `20-requirements/`，不应写在此处。

```markdown
---
doc_id: PRD-NNN
title: "<产品名称> — 产品需求文档"
type: prd
status: draft
version: 0.1.0
updated: YYYY-MM-DD
owner: 产品
---

# <产品名称> — PRD

## 1. 项目概览
### 1.1 背景（市场状况、痛点、机会、价值）
### 1.2 产品定位（一句话说明、目标细分市场、差异化）
### 1.3 目标用户（链接至 Personas.md；核心用户和间接用户）
### 1.4 目标与迭代计划（V1.0 / V2.0 / V3.0 目标和 KPI）

## 2. 行业与竞争对手分析
### 2.1 行业现状
### 2.2 竞争对手（表格：名称、优势、差距、链接）

## 3. 总体需求
### 3.1 核心业务场景（端到端流程、编号步骤）
### 3.2 需求优先级（P0 / P1 / P2 映射至 Epic 列表）
### 3.3 业务约束与限制（合规、本地化、硬件）

## 4. 核心功能需求（摘要）
> 仅使用表格：能力 → Epic ID → 优先级。完整细节位于 `20-requirements/`。
| 能力 | Epic | 优先级 | 备注 |
|------|------|--------|------|

## 5. 非功能需求（摘要 → 链接 NFR.md）

## 6. 样本文档 / 参考资料

## 7. 待决问题

## 版本历史
| 版本 | 日期 | 作者 | 变更 |
|------|------|------|------|
```
