## Why

web-pc 企业版现在只有账户、组织、套餐、通知与复核页面，"数据浏览"显示"即将推出"。扫描、核验、确认与导出只能在 LINE 小程序里做。

负责人 2026-11-07 决定（B-5d）：
- web-pc 做**完整的 OCR 流程**：上传、识别、核验修改、确认、导出、单据浏览；
- 界面参考演示站 saiflow-demo.aibaba.asia，可按需求适当调整；
- admin 后台**不加** OCR 页面。

这与 PRD §4.9"V1.0 的 web-pc 只做结构化数据浏览与管理操作"不同，本变更按负责人的决定更新 PRD。

## What Changes

**web-pc 新页面**（后端沿用 B-3、B-4 已有的接口与规则）：
- **上传（FR-SYS-127）：**
  - 拖放或选择文件（JPG / PNG / PDF，规则同 FR-UPLOAD-003）；
  - 上传队列逐个显示进度，可以取消、重试；
  - 待处理列表可以多选后"开始识别"。
- **识别状态（FR-SYS-128）：**
  - 上传页列出识别中与刚失败的任务，可以取消识别中的任务；
  - 失败的显示原因，并可以"重新识别"。
- **核验（FR-SYS-129）：**
  - 左侧是当前租户中待核验的任务；
  - 中间是原件，可以翻页、放大；
  - 右侧是表头字段与明细表，可以修改；缺少的必填、类型不符、金额不一致都会标出；
  - 可以保存草稿、更换模板（含通用结果）、确认；
  - 显示最近一次退回意见，可以查看修改记录。
- **单据库（FR-SYS-130）：**
  - 取代"数据浏览"；
  - 列出当前租户中可见的任务，可以按阶段、模板、建立日期范围筛选，也可以按文件名查找，每页 20 条；
  - 点开后按阶段进入对应页面。
- **单据详情与导出（FR-SYS-131）：**
  - 原件与只读结果、复核记录、修改记录；
  - 已确认的单据可以导出 Excel，浏览器直接下载。
- **菜单与首页（修改 FR-SYS-094）：**
  - 菜单增加"上传""核验""单据库"，按权限显示，去掉"数据浏览"；
  - 首页增加待核验数量与最近 5 个任务。

**后端（修改 FR-VERIFY-017）：** 任务列表增加按模板与按建立日期范围（泰国日期）筛选，供单据库使用。

**不做：**
- 演示站中的置信度（P1）、Confirm all（P1）、字段旗标；
- 本地文件夹归档（P2）、批量导出（FR-ENTRY-003）、重复单据提示（P1）、报表（P1）；
- 按链接导入（小程序已有，web-pc 本次不做）；
- admin 后台的 OCR 页面。
