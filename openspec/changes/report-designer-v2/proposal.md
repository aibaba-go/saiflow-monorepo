# Report designer V2 and configurable PC home

## Why
已确认的交互稿需落地为可保存、发布、查询的功能；PC 登录首页按个人选择及当前租户呈现，游客保留原首页。

## Scope
- FR-REPORT-019：类型化字段条件、AND/OR、卡片条件与页面显式字段映射，在正式数据聚合前执行。
- FR-REPORT-020：组织私有图片资产、受限 HTML、允许来源的 HTTPS iframe；静态卡不查询、不导出 CSV。
- FR-REPORT-021：横向条形图、主题、卡片背景、圆角、间距、阴影与折线填充。
- FR-SYS-170：菜单折叠展开、本机持久化、键盘可操作与权限一致。
- FR-SYS-171：用户与租户独立保存首页选择，游客原首页、登录自选发布报表或个人/组织基础默认报表首页。

## Non-goals
不开放个人运营报表设计、不修改套餐权限、不加入跨模板 JOIN、任意 SQL、自动刷新、公开分享或可执行 HTML；不提交、推送或部署。

## Confirmation
2026-11-20 用户确认新版设计器及首页方案，并明确要求开始实现三个部分。
