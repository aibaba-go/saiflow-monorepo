## Why

B-2 的后台接口已经齐全，但平台 admin 还没有页面可用。现在批准建组织申请、开通套餐、修改价格，都要在电脑上拼接口命令（B-5a 实测时就是这样批准组织的），容易出错，也没法交给其他同事。PRD §4.9"使用入口"规定 web-pc admin 后台负责平台运营：组织申请审批与停用、企业认证审核、套餐档位与有效期、免费额度与成员人数上限、OCR 引擎与大模型配置。

负责人 2026-11-05 决定 B-5 按应用拆分，B-5b 做 admin 后台。2026-11-06 负责人决定了本 change 的范围：现有后台接口全部做成页面；另加查询用户与查看操作日志；admin 账号仍由服务器命令管理，后台只能修改本人口令；OCR 引擎与大模型配置按 PRD §4.6 做，由本 change 做配置的保存与后台接口，B-3（同事负责）的识别流程读取这些配置。

## What Changes

- **登录与会话（FR-SYS-060）：** 用户名与口令登录；锁定、停用、会话过期时给出提示并回到登录页；首页显示三类待处理事项的数量（建组织申请、企业认证申请、续费与开通申请）。
- **修改本人口令（FR-SYS-061；修改 `identity` 的 FR-SYS-019）：** 已登录的 admin 输入当前口令与新口令修改本人口令；同一账号的其他会话随之失效。新建、停用、重设他人口令仍只能用服务器命令。
- **界面语言（FR-SYS-062）：** 中文（默认）与英文（负责人 2026-11-06）。
- **建组织申请审批（FR-SYS-063）：** 按状态列出，查看详情，批准或填写原因驳回。
- **组织管理（FR-SYS-064）：** 列表与按名称查找；查看资料、状态、企业认证状态、成员人数；修改资料；停用与恢复；直接设定或取消企业认证。
- **企业认证审核（FR-SYS-065）：** 列出申请，查看认证资料，批准或填写原因驳回。
- **订阅与预占（FR-SYS-066）：** 查看租户的订阅历史与预占记录；为租户设定订阅（档位、按月或按年、开始与结束时间，默认值同后端规则）。
- **续费与开通申请审批（FR-SYS-067）：** 按状态列出，批准（可改开始与结束时间）或填写原因驳回。
- **套餐目录与价格（FR-SYS-068）：** 修改每月扫描配额、成员人数上限、按月价与按年价。
- **系统参数（FR-SYS-069）：** 个人与组织的免费额度、组织开通套餐前的成员人数上限。
- **查询用户（FR-SYS-070 页面；新增后端 FR-SYS-080，`identity`）：** 按邮箱、昵称或用户 ID 查找用户，查看注册状态、个人租户，进入该个人租户的订阅与预占。
- **操作日志（FR-SYS-071 页面；修改 `identity` 的 FR-SYS-003）：** admin 可以按时间、操作者类型、操作类型、操作对象筛选，并分页查看操作日志，只读。
- **OCR 与大模型配置（FR-SYS-072 页面；新增后端 FR-SYS-005，新 capability `ocr-settings`）：**
  - 可配置项：首选与备用 OCR 引擎（TextIn、Google Cloud Vision）、单据重试次数（默认 3）、全局切换阈值、首选引擎试探间隔、大模型地址与模型名称；
  - 各项密钥仍放在服务器环境变量文件里，页面只显示"已配置"或"未配置"，不回显明文；
  - 修改写入操作日志；
  - 提供读取接口给 B-3 的识别流程。
- **等待、确认与错误反馈（FR-SYS-073）：** 停用组织、驳回申请、修改套餐与参数等操作前先确认；按钮防重复提交；错误按错误代码显示为当前语言，字段错误显示在对应输入框下。
- **文档同步：**
  - PRD §4.6、§4.9；
  - `NFR.md`：admin 后台的语言；
  - `Architecture.md`；
  - `Data-Model.md`：`DM-SystemSetting` 的 OCR 与大模型参数；
  - EPIC-06：FR-SYS-005 标记已迁移；
  - `Requirements-Index.md`；
  - ADR-006 §7；
  - 部署说明：新增的环境变量。

## Capabilities

### New Capabilities

- `web-admin`：admin 后台的页面行为（新编 `FR-SYS-060` 至 `FR-SYS-073`）。页面调用的后端规则在 `identity`、`tenancy`、`billing`、`ocr-settings` 中定义，本 capability 不重复。
- `ocr-settings`：OCR 引擎与大模型的系统参数（沿用 EPIC-06 的 `FR-SYS-005` 编号，按 PRD §4.6 改写）：保存、校验、后台修改，以及供识别流程读取。

### Modified Capabilities

- `identity`：
  - 修改 FR-SYS-019：admin 可以通过接口修改本人口令；
  - 修改 FR-SYS-003：admin 可以通过接口查询操作日志；
  - 新增 FR-SYS-080：admin 查询用户。

## Non-goals

- 在后台新建、停用 admin 账号或重设他人口令（仍用服务器命令；负责人 2026-11-06）。
- OCR 识别流程本身、引擎的调用与切换逻辑、大模型的调用（B-3，同事负责）。本 change 只做配置与读取接口。
- 在后台编辑密钥：密钥只放在服务器环境变量文件里（PRD §4.6、ADR-008）。
- 模板管理（EPIC-08，P1）、报表（EPIC-07，P1）、置信度阈值（P1）。
- 修改用户资料、停用客户账号：PRD 没有要求。
- 泰语界面。
- 短信 OTP 登录（随短信平台，NFR-SEC-011）。

## 待负责人确认的假设

| # | 假设 | 理由 |
|---|------|------|
| A1 | 全局切换阈值默认为"首选引擎连续失败 5 次"，首选引擎试探间隔默认 300 秒；B-3 实现时可以调整默认值 | PRD §4.6 写明默认值在 B-3 确定，但页面与保存需要初始值 |
| A2 | 首选与备用引擎不能相同；备用引擎可以设为"不使用" | 两个相同的引擎无法互为备用 |
| A3 | 密钥使用的环境变量：TextIn 为 `TEXTIN_APP_ID` 与 `TEXTIN_SECRET_CODE`（同 main），Google Cloud Vision 为 `GOOGLE_VISION_API_KEY`，大模型为 `LLM_API_KEY`；"已配置"指服务器上该变量不为空 | 与 main 一致，B-3 沿用；名称以 B-3 最终使用的为准 |
| A4 | 大模型默认地址为 `https://api.deepseek.com`，默认模型为 `deepseek-flash`（同 main）；地址必须是 https | main 现在用 DeepSeek |
| A5 | 查询用户至少输入 2 个字符，按邮箱或昵称部分匹配，或输入完整的用户 ID；每页最多 50 条 | 避免一次列出全部用户 |
| A6 | 操作日志按时间倒序分页，每页 50 条；可以按时间范围、操作者类型（用户、游客、admin、系统）、操作类型前缀（如 `org.`）与操作对象筛选；查看日志本身不写日志 | 查看是只读操作；记录过多会淹没真正的变更 |
| A7 | admin 修改本人口令后，本账号的其他后台会话失效，当前会话保留；新口令同样至少 12 个字符，且不能与当前口令相同 | 口令疑似泄露时，改口令应能踢掉别人 |
| A8 | 首页的待处理数量取自三类申请中状态为"待审批"的数量 | 现有列表接口可以按状态筛选 |
| A9 | 后台使用 Ant Design 的标准布局（左侧菜单、顶部显示当前 admin 与退出）；参考旧版设置页的结构 | 内部工具，优先可用 |
| A10 | 所有时间按泰国时间（UTC+7）显示；金额以泰铢显示 | 与小程序一致 |
