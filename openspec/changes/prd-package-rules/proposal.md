## Why

PRD v3.1.0 §4.9 的套餐与计量只写了四档月页额度、到期即停、线下续费与到期提醒。负责人于 2026-10-30 按 GTM 套餐表（`docs/90-extra/GTM for AIbaba as of 10.10.pptx.jpg`）补充了计量口径、免费额度、成员人数上限、按月/按年开通、通知渠道、用量提醒，并取消“升级企业须认证”、将“企业租户”改称“团队租户”。这些规则改变 B-2（`rebuild-auth-tenant`）要实现的行为，必须先写进 PRD，否则 B-2 无产品来源。

## What Changes

更新 PRD §4.9 及受影响的产品级文档，写入负责人确认的以下决定（产品层面，不含实现细节）：

| # | 主题 | 决定 |
|---|------|------|
| 1 | 计量单位 | 所有套餐的计量单位改称 **OCR 扫描次数**，每识别一页计一次；四档每月次数不变（Kinder 1,000 / Starter 5,000 / Intermediate 10,000 / Advance 100,000） |
| 2 | 每月配额 | 每月配额在泰国时区自然月月底清零，套餐有效期内次月按档位重新发放；未用完的不结转 |
| 3 | 免费额度 | Kinder 与 Starter 用户注册后获赠一次性免费额度（单位同上，用完为止）；数量待定（见“待确认”） |
| 4 | 成员人数上限 | Kinder 单人；Starter 2 人；Intermediate 5 人；Advance 不限。各档上限由平台 admin 在后台参数中配置 |
| 5 | 团队租户 | Kinder 对应个人租户；Starter 及以上为**团队租户**（原“企业租户”）。**升级为团队租户不需要认证，付费即可**（线下收款后由平台 admin 开通）；团队租户从开通时起算 |
| 6 | 开通周期 | 套餐可按月或按年开通（GTM 定价：Kinder 888/年；Starter 599/月或 5,990/年；Intermediate、Advance 面议）。价格不写入 PRD，由 GTM 维护 |
| 7 | 复核 | 不变：所有档位都可配置无需复核、一级复核或二级复核 |
| 8 | 通知渠道 | 所有档位都有通知与提醒；**短信**只对 Intermediate 与 Advance 提供，且仅发给已提交并通过验证手机号的用户 |
| 9 | 用量提醒 | 当月剩余配额不足 20% 时提醒一次；月末前 3 天如仍有剩余配额，提醒一次；错过不补发 |
| 10 | 到期提醒 | 保留：到期前 7 天、3 天、1 天、到期当天、到期后各一次；错过不补发 |
| 11 | 其他档位差异 | 模板（Fix / Limited / Adjustable / Customize）、看板、对接、应用维持原规划（模板管理与报表 P1，对接 V2.0）；V1.0 只记录档位差异，不实现 |
| 12 | 已确认保留 | 游客数据仅本人可见 |

## 评审结论（负责人，2026-10-30）

| # | 问题 | 结论 |
|---|------|------|
| Q1 | 免费额度 | 每个用户只送一次。数量与“自动开通一个月 Kinder”的关系未定，登记为 PRD 开放问题（OQ-28），B-2 前关闭；在此之前保留现有的自动开通 |
| Q2 | 企业认证 | 不阻碍升级与付费；任何时候都可以申请；只用于后续可能规划的开发票功能，其余场景仅身份显示不同，对业务无影响。保留在 V1.0（申请、审核或 admin 直接开通），权限点“企业认证申请”保留 |
| Q3 | 名称 | Starter 及以上的租户统一改称 **团队租户**（不是所有团队都是企业） |
| Q4 | 通知渠道 | 全档：LINE OA 消息、邮件（有邮箱时）、站内通知；Intermediate 与 Advance 另加短信（仅已验证手机号） |
| Q5 | 用量提醒收件人 | 团队租户发给 owner；个人租户发给本人 |
