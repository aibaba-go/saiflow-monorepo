# Delta Spec: web-pc/shell-auth

## Purpose

为 Web PC 前端原型提供登录、全局布局导航与 UI 语言切换能力，以 Mock 会话模拟账户与角色，是所有其他页面的入口外壳。原型不接入真实鉴权服务。

## ADDED Requirements

### Requirement: 登录与 Mock 会话

系统 SHALL 提供登录页；用户使用 Mock 凭据登录后进入工作台首页，并在整个应用会话期间保持登录状态（刷新页面不丢失）。未登录状态访问任何受保护页面时，系统 SHALL 重定向到登录页。（来源：FR-SYS-001，原型以 Mock 会话实现）

#### Scenario: 成功登录进入工作台

- **WHEN** 用户在登录页输入 Mock 凭据并提交
- **THEN** 系统进入工作台首页，并显示当前用户与角色

#### Scenario: 未登录访问受保护页面被重定向

- **WHEN** 浏览器直接打开核验工作台路由且无登录状态
- **THEN** 系统重定向到登录页，登录成功后回到原目标页面

#### Scenario: 退出登录

- **WHEN** 用户点击退出登录
- **THEN** 会话清除，访问受保护页面时再次重定向到登录页

### Requirement: 全局布局与按角色导航

系统 SHALL 提供统一的应用布局（侧边导航 + 顶部栏），并按用户角色显示/隐藏菜单项：`clerk` 可见上传、核验、录入归档、归档管理；`viewer` 不可见上传与核验入口；`admin` 额外可见设置菜单。（来源：FR-SYS-002）

#### Scenario: clerk 角色看到核心菜单

- **WHEN** 以 `clerk` 角色登录
- **THEN** 侧边导航显示上传、核验、录入归档、归档管理入口，且不显示设置菜单

#### Scenario: viewer 角色菜单受限

- **WHEN** 以 `viewer` 角色登录
- **THEN** 侧边导航不显示上传与核验入口，仅显示归档管理等只读入口

### Requirement: UI 语言切换

系统 SHALL 支持泰语 / 英语 / 简体中文三种 UI 语言，默认泰语；切换 SHALL 立即生效且无需重启或刷新页面。所有面向用户的字符串 SHALL 来自外部化资源包，不得硬编码。（来源：FR-SYS-004、NFR-I18N-003）

#### Scenario: 切换语言立即生效

- **WHEN** UI 当前为泰语，用户将语言切换为英语
- **THEN** 所有导航、按钮与表头文案立即更新为英语

#### Scenario: 语言偏好在会话间保留

- **WHEN** 用户将语言切换为中文后刷新页面
- **THEN** UI 仍以中文显示
