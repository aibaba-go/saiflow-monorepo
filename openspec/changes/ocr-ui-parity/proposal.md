## Why

`ocr-scan-flow` 把 main 分支已跑通的扫描流程迁了过来，但小程序页面只按 main 的逻辑做了主干。界面与 main 差别很大，main 已有的几项功能也没有做：按链接导入、首页最近任务、上传队列的取消与重试、配额横幅、结果页的三种视图与重置、模板面板的推荐与字段预览、历史的文件名搜索。

负责人 2026-11-06 决定：
- 小程序 OCR 流程的页面**尽量照抄 main 的界面**；
- 后端保留现有功能，补上 main 页面需要而缺少的能力；
- 设计文档中属于 OCR 流程、优先级为 P0、但代码中还没有的部分，按设计文档补全。

## What Changes

**小程序页面（按 main 的 Vue 页面照抄为 React，保留现有的接口与规则）：**
- **扫描首页**（main `ScanHomePage.vue`）：
  - 工作区切换菜单；
  - 配额横幅：套餐名、本月剩余 / 总量、"套餐"入口；
  - 到期与即将到期的提示；
  - 拍照、选择文件、**按链接导入**；
  - 上传框：
    - 逐个文件的进度与状态；
    - 取消单个文件，或取消全部未完成的文件（先确认）；
    - 重试失败的文件；
    - 完成后的汇总；
  - 待处理列表：全选、多选后"处理所选"或"删除所选"（先确认）；
  - **最近任务**（最新 10 条），点开按阶段进入对应页面；
  - 通知入口。
- **确认页**（`ConfirmPage.vue`）：
  - 多个文件时逐个浏览（上一个 / 下一个），多页文件逐页翻看；
  - "开始识别（n 个文件）"；
  - 部分已开始时显示已开始的数量，可以继续开始剩下的；
  - 所选文件已不可用、登录状态或租户已变化时，提示返回首页。
- **识别进度页**（`ProcessingPage.vue`）：
  - 步骤与页数；
  - "可以离开本页，任务在后台继续"的说明，以及"返回首页"；
  - 取消任务（先确认）。
- **结果页**（`ResultPage.vue`、`StructuredDataView.vue`）：
  - "表格 / 原件 / JSON"三种视图，JSON 可以复制；
  - 更新时间等元信息；
  - 表头字段与明细行的增删，字段名必填、不得重复；
  - **重置**：放弃本次未保存的修改，回到最后保存的结果（先确认，与 main 相同）；
  - 游客提示、已确认后的锁定提示；
  - 模板面板：
    - 推荐模板与匹配度，匹配度低时提示；
    - 先预览模板字段，再"应用"；
    - 有未保存修改时"保存并切换"；
    - 匹配中、应用中的状态；
    - 转换失败、类型或精度不符的提示；
    - 超过 10 分钟仍未完成的提示；
    - 没有可用模板时的提示。
- **最终结果页**（`FinalResultPage.vue`）：
  - 导出时显示"正在准备 / 已就绪 / 正在用手机浏览器下载"；
  - "再扫一张"。
- **历史**（`HistoryPage.vue`）：按文件名搜索，并保留阶段筛选与"加载更多"。
- **公共部件**：
  - 页头、状态标签、任务列表项；
  - 全屏原件查看器（`ImageViewer.vue`）：双指缩放、双击放大、拖动、放大 / 缩小 / 还原按钮、多页滑动翻页。
- **样式**：页面结构、文字层级、颜色与间距照抄 main 的样式。语言仍为英语（默认）、泰语、中文。

**模板匹配不到时用自由格式（负责人 2026-11-06 重申，D4）：**
- 没有已发布的模板、自动匹配的最高匹配度低于 70%、或者自动转换缺少主要字段时，结果直接按"自由格式"（界面称"通用结果"）显示，任务进入待核验，**不作为错误提示**；
- 用户仍可以在"更换模板"中选择模板；用户**手动**选择的模板与单据不符时，才提示"所选模板与单据不符"；
- 与 main 的差别：main 只要有模板，就总是按最接近的模板转换（只提示匹配度低），只有没有模板或转换失败时才用通用结果；本变更按负责人的规则改为低于 70% 即用自由格式；
- 不需要为其他单据类型预设模板。

**后端（保留现有接口，只补缺）：**
- **按链接导入（新）：** 用户给出一个公开文件的网址，后端下载后按上传的同一规则检查，然后放入待处理。为防止被用来访问内部地址，只允许公网地址；重定向后的每个地址都要再检查一次；限制大小与时间。
- **金额校验（FR-OCR-013，从 EPIC-02 迁入）：**
  - 检查明细行的"数量 × 单价 = 金额"，以及单据合计与明细、税额的关系；
  - 不一致时标记出来，在结果页显示，**不自动改值**。
- **标准化（FR-OCR-016，从 EPIC-02 迁入）：**
  - 日期：佛历与公历统一为 `YYYY-MM-DD`；
  - 数字：去掉千位分隔符；
  - 泰铢：两位小数的十进制文字；
  - 文本：去掉首尾空白；
  - 已有部分实现，补齐并写明规则。
- **模板匹配的展示信息：** 每个可选模板的匹配度与推荐顺序；转换时的类型或精度提示；单个模板版本的字段定义（供预览）。
- main 页面需要、目前没有的读取：单个文件的信息、单个导出的状态。

## Capabilities

无。

### Modified Capabilities

以下能力来自 `ocr-scan-flow`。它们还没有归档到 `openspec/specs/`，所以**本变更须在 `ocr-scan-flow` 归档之后再归档**：
- `documents`：新增 FR-UPLOAD-014 按链接导入。
- `recognition`：修改 FR-OCR-019 大模型匹配模板（匹配不到时直接用自由格式）与 FR-OCR-023 通用结果；新增 FR-OCR-013 金额校验、FR-OCR-016 标准化（从 EPIC-02 迁入，沿用原 ID），以及 FR-OCR-024 模板匹配的展示信息。
- `line-mini`：新增 FR-SYS-109 首页的配额与最近任务、110 上传队列与按链接导入、111 待处理的多选、112 确认页逐个浏览、113 原件查看器、114 结果页的视图与重置、115 更换模板面板、116 识别进度与最终结果的补充、117 历史搜索、118 界面与 main 一致。`ocr-scan-flow` 中的 FR-SYS-056～059、105～108 不改。

## 待负责人确认的假设

| # | 假设 | 理由 |
|---|------|------|
| A1 | 链接导入只接受 `http`、`https` 的公网地址：拒绝内网、本机、链路本地地址，重定向最多 3 次、每次都检查；下载上限 20 MB，总时长 20 秒；导入后与上传的文件一样进入待处理，不自动开始识别 | main 的上限；main 没有地址检查，补上以防止访问内部服务 |
| A2 | 金额不一致只做标记与提示，不阻止确认，也不改值 | OCR-Pipeline §5.3"不得静默猜测"；PRD 未要求阻止确认 |
| A3 | 金额容差为 ±0.01 THB；没有数量、单价或合计字段的模板不做对应的检查 | EPIC-02 §4.2 |
| A4 | （已改，负责人 2026-11-06 选 A）结果页的"重置"照抄 main：只放弃未保存的修改，回到最后保存的结果，不生成新版本；不做"恢复为识别结果" | main 的 Reset 即如此；最初把它误写成"恢复为识别结果" |
| A5 | 照抄 main 的界面时，main 与本仓库的规则冲突的地方以本仓库的规格为准，例如权限、套餐判断与下载凭证 | 规格是约束；界面照抄不改规则 |
| A6 | 结果页的 JSON 视图显示的是当前版本的结构化结果，不显示 OCR 原始载荷 | 原始载荷只供审计；main 的 JSON 视图也是结构化结果 |
