# 新服务器晋升生产，原生产改为测试

## Why

负责人确认将 130.94.24.117 晋升为生产，将 38.60.156.234 改为测试；保持现有三个生产域名、LINE 配置和生产业务数据。按 AI-WORKFLOW §3 采用 M 级变更，关联 FR-PLAT-005、FR-PLAT-006、NFR-SEC-009、NFR-DATA-005。

## What Changes

- 手动 Deploy 增加 production/test 目标，凭据和变量按 GitHub Environment 分开；保留分支、CI、健康检查、备份与数据库非公网门禁。
- 复制实际运行且 CI 通过的镜像、服务端配置及 TLS 证书；暂停旧服务写入后最终备份，恢复并比对新生产数据库。
- DNS 由负责人稍后切换。过渡期旧服务器仅将现有生产域名反向代理到新服务器，生产始终只有一个写入库。
- 旧服务器的测试库从空库初始化；生产备份保留用于恢复。暂共用原 GCS 业务桶，测试禁用识别/清理、提醒、SMTP 与 LINE 实际频道；新生成对象使用随机标识，测试库不保留生产对象引用。
- 更新 ADR-008 和部署运维说明。不修改业务接口、模型或需求优先级。

## Non-goals

- 不修改 DNS、LINE Developers、GCP IAM 或桶资源；不调用付费 OCR 或发送实际邮件。
- 不创建真实客户账号；不更改管理员密码；不将凭据纳入版本管理。
- 未获明确提交/推送授权前，双环境 workflow 仅在本地准备和验证；现有已提交 workflow 的仓库级生产配置切到新服务器，测试配置先存 GitHub test Environment。
