## Why

PRD §2 的统一流程是"录入 → 解析 → 确认 → 复核（可选）→ 写入正式业务数据"。B-3 做到了"确认"：确认后任务就是终态，复核与"正式业务数据"都还没有。EPIC-03 中复核相关的 P0（FR-VERIFY-010～013）与修改记录（FR-VERIFY-007）也还没有实现。

负责人 2026-11-07 决定（B-4 范围）：
- 复核层级由组织 owner **按模板**设置 0 / 1 / 2 级；个人租户不复核；
- 复核人退回时，单据**回到待核验**，附退回意见，解锁可改；重新确认后从一级重新开始；
- 复核人**不能是确认人**，二级复核人也**不能是一级复核人**，owner 不例外；
- 范围：小程序的复核页面、web-pc 的复核页面、字段修改记录（FR-VERIFY-007）；
- 不做：批量 Excel 导出（FR-ENTRY-003）。

## What Changes

**复核（新能力 `reviews`）：**
- **复核设置（FR-VERIFY-010）：** owner 为每个已发布模板与"通用结果"各设一个层级（0 / 1 / 2，默认 0）。修改只影响之后的确认，已在复核中的单据按原层级走完。
- **进入复核（FR-VERIFY-011）：** 确认时按所确认结果的模板读出层级：
  - 0 级：直接"已确认"，即正式业务数据（与现在相同）；
  - 1 / 2 级：进入"待一级复核"。
- **复核队列（FR-VERIFY-019，新编号）：**
  - 持有"一级复核"的成员看到本组织全部待一级复核的单据，持有"二级复核"的看到待二级复核的；
  - 不受"数据浏览"限制；
  - 可以打开查看原件、结果（只读）、修改记录与复核记录。
- **通过（FR-VERIFY-012）：**
  - 一级通过：1 级流程成为正式业务数据，2 级流程进入待二级复核；
  - 二级通过：成为正式业务数据。
- **退回与复核记录（FR-VERIFY-013）：**
  - 退回须填意见，单据回到待核验并解锁；
  - 每次通过或退回都留下复核记录：轮次、级别、复核人、时间、决定、意见。

**待复核通知（修改 `notifications`，负责人 2026-11-07）：**
- 单据进入某一级复核时，给能处理它的复核人发站内通知（FR-SYS-126）；站内通知总是发送。
- 其他方式由 owner 在复核设置中选择开启，默认关闭。本变更只提供邮件；LINE 消息与短信后续接入。
- 小程序与 web-pc 的通知中心显示待复核通知，点开进入复核详情（FR-SYS-054、FR-SYS-103）。

**结果（修改 `results`）：**
- 确认通过检查后按复核层级处理（FR-VERIFY-009）。
- "待复核"与"已确认"都锁定，退回后解锁（FR-VERIFY-006）。
- 任务阶段增加"待复核"（一级 / 二级）；"已确认"改为表示正式业务数据（FR-VERIFY-017）。本变更之前已确认的任务仍为"已确认"。
- **修改记录（FR-VERIFY-007）：** 每次保存生成新版本时，逐字段记录修改前、修改后、修改人与时间。切换模板记为一条"更换模板"。

**导出（修改 `exports`）：**
- 待复核的任务不能导出，复核通过后才能导出（FR-ENTRY-015）。
- 不需要复核的单据（个人租户、组织中设为 0 级的模板）确认后即为"已确认"，可以导出（负责人 2026-11-07）。

**小程序（修改 `line-mini`）：**
- 首页"待复核"入口（FR-SYS-119）。
- 复核队列与复核详情：通过、退回（FR-SYS-120）。
- owner 在组织页设置复核层级（FR-SYS-121）。
- 修改记录的查看（FR-SYS-122）。
- 已有页面的改动：
  - 结果页显示最近一次退回意见；
  - 确认后进入最终结果页，最终结果页显示复核状态与复核记录，待复核时不显示"导出 Excel"；
  - 历史增加"待复核"筛选。

**web-pc（修改 `web-pc`）：**
- 菜单增加"复核"与"复核设置"。
- 复核队列（FR-SYS-123）。
- 复核详情（FR-SYS-124）。
- 复核设置（FR-SYS-125）。

**不做：**
- Confirm all（P1）；
- 批量更正（FR-VERIFY-003，P1）；
- 批量 Excel 导出（FR-ENTRY-003）；
- 置信度标记（P1）；
- LINE 消息与短信通知（后续接入）；
- 关闭确认环节（OQ-11）：仍然必须确认。

## Capabilities

### New Capabilities
- `reviews`: 复核层级设置、确认后进入复核、复核队列与查看、通过、退回与复核记录。

### Modified Capabilities
- `results`:
  - 确认后按复核层级处理（FR-VERIFY-009）；
  - 锁定范围（FR-VERIFY-006）；
  - 任务阶段（FR-VERIFY-017）；
  - 新增修改记录（FR-VERIFY-007）。
- `exports`: 只有已确认（正式业务数据）的任务可以导出（FR-ENTRY-015）。
- `notifications`: 新增待复核通知（FR-SYS-126）。
- `line-mini`:
  - 已有要求的改动：通知中心（FR-SYS-054）、结果页（FR-SYS-105）、确认（FR-SYS-106）、最终结果（FR-SYS-107）、历史（FR-SYS-108）；
  - 新增：复核入口、复核队列与详情、复核设置、修改记录（FR-SYS-119～122）。
- `web-pc`:
  - 菜单（FR-SYS-094）、通知中心（FR-SYS-103）；
  - 新增：复核队列、复核详情、复核设置（FR-SYS-123～125）。

- **后端：**

- **web-pc：** 菜单、复核队列、复核详情（原件与只读结果）、复核设置。
- **文档：** PRD（OQ-6 结论）、EPIC-03（FR-VERIFY-007、010～013 标为已迁移）、Data-Model、Glossary（待复核）、Requirements-Index。
- **不影响：** admin 后台、识别与模板转换流程本身。
