## Why

PRD v3.0.0（`docs/10-product/PRD-SaiFlow.md`）已生效，但 §8 同步清单全部未完成，下游产品级文档仍描述 v2 的单入口 OCR 与 Cloud SQL 关系投影。同时，账户、租户与计费这套商业模型已写入 `EPIC-06` 与 `Data-Model.md`，PRD 中却几乎没有（PRD 中“订阅”“套餐”“游客”出现 0 次），按“禁止臆造需求”规则它尚无产品来源。B-2 重建认证与租户之前，必须先把它补进 PRD（ADR-006 §7 B-0）。

## What Changes

1. **PRD 新增一节“账户、租户与计费”**，写入负责人在 2026-10-30 探索中确认的以下 11 项决定（产品层面，不含表名、接口等实现细节）：

   | # | 主题 | 决定 |
   |---|------|------|
   | 1 | 范围 | 租户、套餐（Kinder / Starter / Intermediate / Advance，每月 1,000 / 5,000 / 10,000 / 100,000 页）、按月页数计量、到期即停（不能新建识别，历史可查看）、线下续费与升级、到期提醒（到期前 7/3/1 天、当天、过期后）均属于 **V1.0（P0）** |
   | 2 | 预设角色 | 只预设两个角色：平台 `admin`（技术团队，跨租户：修改后台数据、开通/关闭租户、修改租户信息、线下收款后修改租户余额与有效期）与租户 `owner`（本租户全部权限）；其余角色由 owner 在运行期自定义，可组合的**权限点**在设计期确定 |
   | 3 | 默认角色 | 成员加入企业后自动获得该企业的默认角色；owner 可修改默认角色的权限 |
   | 4 | 用户与租户 | 用户与租户多对多；每个用户有一个个人租户；**个人租户不能邀请成员** |
   | 5 | 企业 | “升级为企业用户” = 另建企业租户，个人租户保留；企业认证由用户提交、admin 审核后开通，或由 admin 在后台直接开通 |
   | 6 | 游客 | 保留免登录试用；游客进入时即建立临时租户并开通一个月 Kinder |
   | 7 | 注册 | 两个入口：LINE OA 底部菜单的 `register` 按钮，以及试用到结果页“确认”时弹出；两者走同一注册流程（邮箱经验证必填、手机号选填、记录 LINE 身份 ID），注册成功后当前游客数据归入个人租户 |
   | 8 | 身份 | 内部唯一主键为用户 ID；LINE 身份 ID、邮箱、手机号以及将来的 Google / Facebook OAuth 均作为关联身份指向该主键；LINE OA、LIFF 小程序与 web-pc 的 LINE 登录必须建在同一个 LINE Provider 下 |
   | 9 | 登录 | LINE 小程序与 web-pc 企业版使用 LINE 登录；web-pc admin 后台使用独立账号（用户名 + 密码），接入短信平台后再加短信 OTP |
   | 10 | 入口 | LINE 小程序：游客试用、上传、核验、确认、管理操作；web-pc 企业版：管理层浏览结构化数据、管理操作；web-pc admin 后台：平台运营。成员与角色管理、复核等管理操作在小程序与 web-pc 两端都提供 |
   | 11 | web-pc 范围 | V1.0 的 web-pc 企业版只做结构化数据浏览与管理操作；报表（EPIC-07，P1）、应收应付跟踪（V2.0）、单据比对与异常识别（V2.0）维持原规划 |

   **权限点清单**（负责人确认，2026-10-30；随“账户、租户与计费”一节写入 PRD）：

   | 权限点 | 说明 | owner | 默认角色（初始值，owner 可改） |

   | 核验他人单据 | 修改并确认本租户其他成员的单据 | ✓ | |
   | 一级复核 | | ✓ | |
   | 二级复核 | | ✓ | |
   | 导出 | 导出 Excel | ✓ | ✓ |
   | 数据浏览 | 浏览本租户全部结构化数据（web-pc 管理层主要用途） | ✓ | |
   | 成员管理 | 邀请、移除成员 | ✓ | |
   | 角色管理 | 定义角色、分配角色、修改默认角色 | ✓ | |
   | 套餐申请 | 提交续费、升级申请 | ✓ | |
   | 企业认证申请 | 提交企业认证材料 | ✓ | |

   - 没有“数据浏览”权限的成员只能看到和处理本人提交的单据。
   - 平台 `admin` 的能力（开通/关闭租户、修改余额与有效期、审核企业认证、配置 OCR 引擎与大模型）属于平台层，不在租户权限点中，不能分配给租户内的角色。
