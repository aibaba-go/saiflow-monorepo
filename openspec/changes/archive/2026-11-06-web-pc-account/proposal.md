## Why

B-2 的客户接口已经齐全，B-5a 已经在 LINE 小程序里做好了账户、组织、套餐和通知页面，但 web-pc 企业版至今只有健康检查页。PRD §4.9"使用入口"规定 web-pc 企业版面向企业管理层，负责"浏览结构化数据、管理操作"，并且"成员与角色管理、复核等管理操作在 LINE 小程序与 web-pc 企业版两端都提供"。在电脑上管理成员、角色和套餐，比在手机上方便。

负责人 2026-11-05 决定 B-5 按应用拆分，B-5c 做 web-pc 企业版。2026-11-06 负责人确定了范围：管理功能与小程序一致；结构化数据浏览要等识别与核验（B-3、B-4），不在本 change。

## What Changes

本 change 只做前端（`apps/web-pc`），后端接口全部沿用 B-2 已有的。

- **LINE 登录与会话（FR-SYS-090）：**
  - web-pc 没有游客，未登录时显示登录页，用 LINE 网页授权登录（授权码方式，后端已支持，FR-SYS-001）；
  - 登录后回到原来要打开的页面；
  - 在 LINE 授权页取消，或登录失败时，回到登录页并提示；
  - 会话过期时回到登录页并提示，重新登录后回到原页面。
- **未注册用户（FR-SYS-091）：** 用 LINE 登录但还没注册的用户，只看到"请先在 LINE 中完成注册"，页面给出小程序注册入口的链接与二维码；注册完回到 web-pc 刷新即可。web-pc 不提供注册（负责人 2026-11-06）。
- **退出登录（FR-SYS-092）：** 先确认再退出，退出后回到登录页。
- **界面语言（FR-SYS-093）：** 英语（默认）、泰语、中文，在页面顶部切换（负责人 2026-11-06，NFR-USAB-003）。
- **布局与首页（FR-SYS-094）：**
  - 左侧菜单、顶部显示当前租户、未读通知数、语言和用户；
  - 首页显示当前租户的用量；
  - "数据浏览"显示"即将推出"。
- **个人资料（FR-SYS-095）：** 修改昵称与手机号，更换邮箱（验证码），与小程序相同。
- **租户切换（FR-SYS-096）：** 在个人租户与本人所属的组织之间切换，本机保存；每次打开切换列表都重新读取（与 B-5a 的修复 `0468ef9` 一致）。
- **建组织申请（FR-SYS-097）：** 提交申请，查看本人的申请与驳回原因。
- **组织资料与成员（FR-SYS-098）：**
  - 查看与修改组织资料，查看成员与人数上限，移除成员，分配角色；
  - 邀请成员时显示可复制的邀请链接与二维码，对方在 LINE 小程序里打开并接受（负责人 2026-11-06）。
- **角色管理（FR-SYS-099）、owner 转让与退出组织（FR-SYS-100）、企业认证申请（FR-SYS-101）：** 规则与小程序相同。
- **套餐、用量与续费申请（FR-SYS-102）：** 四档套餐与价格、当前档位与用量、按档位规则提交申请。
- **通知中心（FR-SYS-103）：** 未读数、列表、标记已读、全部已读，按当前语言显示。
- **等待、确认与错误反馈（FR-SYS-104）：** 按钮防重复提交，危险操作先确认，错误按错误代码显示为当前语言，字段错误显示在对应输入框下。
- **文档同步：**
  - PRD §4.9：web-pc 不提供注册，未注册用户引导到小程序注册；
  - `Architecture.md`：web-pc 的页面与登录流程；
  - `Requirements-Index.md`：新增 FR-SYS-090～104；
  - ADR-006 §7：B-5c 一行改为确定的名称与范围；
  - 部署说明：核对 LINE 登录回调地址，web-pc 打包时需要 LIFF ID（生成邀请链接和注册链接）。

## Capabilities

### New Capabilities

- `web-pc`：web-pc 企业版的页面行为（新编 `FR-SYS-090` 至 `FR-SYS-104`）。页面调用的后端规则在 `identity`、`tenancy`、`billing`、`notifications` 中定义；与小程序相同的业务规则引用 `line-mini` 的对应条目，不重复定义。

### Modified Capabilities

（无。后端行为不变，`line-mini` 不变。）

## Non-goals

- 结构化数据浏览、上传、识别、核验、复核、导出、历史（B-3、B-4 之后的 B-5d 起）。
- 报表（EPIC-07，P1）、模板管理（EPIC-08，P1）。
- 游客试用：web-pc 只用 LINE 登录（PRD §4.9 登录方式表）。
- 在 web-pc 注册，或在 web-pc 接受邀请：注册与接受邀请仍在 LINE 小程序里完成（负责人 2026-11-06）。
- 通过 LINE 分享邀请链接：电脑上没有 LINE 分享，改为复制链接与二维码。
- 修改后端接口或业务规则。
- Google、Facebook 等其他登录方式。

## 待负责人确认的假设

| # | 假设 | 理由 |
|---|------|------|
| A1 | web-pc 的 LINE 网页登录使用与 LIFF 同一个 LINE Login 频道（现为 `2012285576`），回调地址为 `https://saiflow-app.aibaba.asia/login`，需要在 LINE Developers 中登记，并写入服务器 `.env` 的 `LINE_LOGIN_REDIRECT_URIS` | 同一频道才能得到相同的 LINE 身份 ID（NFR-COMPAT-008）；后端只认一个 `LINE_CHANNEL_ID` |
| A2 | 登录请求带一个随机的 `state`，只在本次浏览器会话中保存；回调时 `state` 不一致、缺失或超过 10 分钟，web-pc 拒绝登录并提示重试 | 防止跨站伪造登录；B-2a 的约定是由前端校验 `state` |
| A3 | 小程序注册链接为 `https://liff.line.me/<LIFF_ID>?entry=register`，邀请链接为 `https://liff.line.me/<LIFF_ID>?invite=<凭据>`，与小程序相同 | 注册与接受邀请都在小程序里完成 |
| A4 | 页面布局：左侧菜单为首页、组织、角色、套餐、通知、个人资料、数据浏览（即将推出）；当前租户不是组织时，"组织"与"角色"显示"请先切换到组织" | 与小程序的页面一一对应，适合电脑屏幕 |
| A5 | 没有权限的操作不显示，规则与小程序相同（FR-SYS-046） | 两端一致 |
| A6 | 所有时间按泰国时间（UTC+7）显示，金额以泰铢显示 | 与小程序、admin 后台一致 |
| A7 | 浏览器最小宽度 1280 像素，更窄时可以横向滚动，不专门适配手机 | 面向电脑；手机用户使用 LINE 小程序 |
| A8 | 会话过期、退出与切换用户时，清除页面上缓存的数据，不显示上一个用户的内容 | 同一台电脑可能有多人使用 |
