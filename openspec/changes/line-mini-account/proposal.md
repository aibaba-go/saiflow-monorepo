## Why

B-2 已经完成后端的身份、组织与权限、套餐与计量、提醒与通知，但三个前端仍是空壳，用户没有任何可以操作的页面。LINE 小程序是一线员工、个人用户与游客的主入口（PRD §4.9"使用入口"），先让它接上已有的后端，用户才能登录、注册、建组织、邀请成员、查看用量与通知。

负责人 2026-11-05 决定：B-5 按应用拆分，每个应用一个 change，先做 LINE 小程序；页面参考旧版（`legacy/apps/line-mini`）的结构，用 Ant Design Mobile 重做；界面提供英语（默认）、泰语、中文三种语言；套餐页显示价格，价格保存在后端套餐目录。上传、识别、核验的页面依赖 B-3、B-4（同事负责），等它们完成后另行做。

| change | 范围 |
|---|---|
| **B-5a `line-mini-account`**（本 change） | LINE 小程序：启动与身份、底部导航、登录、注册、登出、个人中心、语言、租户切换、建组织申请、组织与成员管理、接受邀请、套餐（含价格）与用量、续费申请、通知中心；后端套餐目录增加价格与客户可查看的目录 |
| B-5b（暂定 `web-admin-console`） | admin 后台 |
| B-5c（暂定 `web-pc-account`） | web-pc 企业版的登录与管理操作 |
| B-5d 及以后 | 上传、识别、核验、历史等页面（在 B-3、B-4 之后，各端） |

## What Changes

- **启动与身份（FR-SYS-040）：** 打开小程序时用已有会话进入主界面，没有会话就建立游客会话；启动时显示品牌等待画面；LIFF 初始化超时或失败时提示并可重试。残留的 LIFF 登录状态不会自动登录。
- **LINE 登录（FR-SYS-041）：** 游客在"我的"页点击登录，经 LINE 授权后登录；LINE OA 底部菜单的 `register` 入口打开小程序时直接进入登录与注册。
- **注册（FR-SYS-042）：** 已登录未注册的用户填写邮箱（必填，默认取 LINE 提供的邮箱，须验证码确认）、手机号（选填）、昵称后完成注册。
- **登出（FR-SYS-043）：** 确认后退出，回到游客首页；退出失败时锁定界面并提示重试，不能继续用旧身份操作。
- **底部导航（FR-SYS-056）：** 首页 / 历史 / 报表 / 我的；"报表"只在当前租户是组织、有有效的 Starter 或更高档位订阅、且本人持有"报表查看"权限时显示。
- **个人中心与语言（FR-SYS-044、FR-SYS-004）：** 查看与修改昵称、手机号，更换邮箱；切换英语、泰语、中文，默认英语，立即生效并记住选择。
- **租户切换（FR-SYS-046）：** 在个人租户与本人所属的组织之间切换，刷新后保持；按当前租户与本人权限显示可用的操作。
- **建组织申请（FR-SYS-047）：** 已注册用户填写组织资料提交申请，查看本人申请的状态与驳回原因。
- **组织管理（FR-SYS-048～FR-SYS-051）：** 查看与修改组织资料；成员列表、生成与撤销邀请链接、移除成员、分配角色；角色的新建、修改与删除；owner 转让与退出组织；提交企业认证申请并查看状态。
- **接受邀请（FR-SYS-052）：** 打开邀请链接，未登录或未注册时先完成登录与注册，再加入组织。
- **套餐与用量（FR-SYS-053）：** 查看当前租户的档位、有效期、本月配额、已用与剩余次数、免费额度；查看套餐目录（含按月价、按年价，未设定的显示"联系我们"）并提交续费或开通申请，查看申请状态。
- **套餐价格（修改 `billing` 的 FR-SYS-030）：** 后端套餐目录增加按月价与按年价，初始值取 GTM 资料（Kinder 888/年；Starter 599/月、5,990/年；Intermediate 与 Advance 未设定），admin 可修改；客户（含游客）可以查看套餐目录。
- **通知中心（FR-SYS-054）：** 未读数提示，按时间倒序查看通知，按当前语言显示文字，标记已读。
- **等待与错误反馈（FR-SYS-055）：** 所有请求与按钮都有可见的等待状态，防止重复提交；后端错误按错误代码显示为当前语言的可操作提示。
- **首页、历史与报表：** 在 B-3、B-4 与报表能力之前显示"即将推出"的占位内容（FR-SYS-056）。
- **文档同步：** PRD §4.6 与 §4.9（默认语言改为英语、套餐价格由后台维护、使用入口）、`NFR.md` 的 NFR-USAB-003（默认英语）、`Architecture.md` 前端部分、`Data-Model.md`（`DM-Plan` 的价格）、EPIC-06（FR-SYS-004 标记已迁移）与 `Requirements-Index.md`（FR-SYS-004、040～044、046～056）、ADR-006 §7（B-5 拆分）。

## Capabilities

### New Capabilities

- `line-mini`：LINE 小程序的账户、租户、套餐与通知页面行为（新编 `FR-SYS-040` 至 `FR-SYS-044`、`FR-SYS-046` 至 `FR-SYS-056`；语言沿用 EPIC-06 的 `FR-SYS-004`，按负责人决定改为默认英语）。
  - 页面调用的后端能力已在 `identity`、`tenancy`、`billing`、`notifications` 中定义，本 capability 只规定用户在小程序上看到和操作的行为，不重复后端规则。
  - EPIC-06 中旧版的前端细节（LIFF 20 秒超时、登出锁定、认证意图与任务续接分开保存）作为参考答案，按本 change 的范围改写；与识别任务相关的部分（结果页 Continue 触发注册、确认前的套餐分流）留到 B-5d。

### Modified Capabilities

- `billing`：修改 FR-SYS-030（套餐目录增加按月价与按年价，admin 可修改；客户可以查看套餐目录）。

## Non-goals

- 上传、识别、核验、结果、历史页面，以及游客试用到结果页时弹出注册（B-5d，依赖 B-3、B-4）。
- web-pc 企业版、admin 后台（B-5b、B-5c）。
- 头像上传、组织执照照片（依赖文件上传，B-3 之后）。
- LINE OA 消息、短信、手机号验证。
- 在线支付与按价格收费：价格只用于展示，付款一律线下进行。
- 套餐价格之外的后端接口新增或修改。本 change 发现其他后端缺口时记为 open question，不在本 change 中改后端。
- 报表的内容（EPIC-07，P1）：本 change 只提供"报表"标签与占位页面。

## 待负责人确认的假设

| # | 假设 | 理由 |
|---|------|------|
| A1 | 首页、历史与报表在相应能力完成之前显示"即将推出"的占位内容，首页另显示当前租户的用量卡片与通知入口（负责人 2026-11-05 同意） | 保持导航结构稳定，后续只需替换内容 |
| A2 | 组织、套餐、通知中心、个人资料都从"我的"页进入；通知入口另在首页右上角显示未读数 | 与旧版一致 |
| A3 | 当前租户只记在本机（非凭据），默认个人租户；记住的组织已不可用（被移除、停用）时回到个人租户并提示 | 后端对不可用的租户一律返回 404 |
| A4 | LINE OA 的 `register` 入口打开小程序时带一个参数，直接进入登录；登录后未注册的显示注册框 | PRD 的注册入口 ① |
| A5 | 邀请链接是带邀请凭据的小程序链接，由成员通过 LINE 分享；凭据在登录与注册期间只保存在本页会话中，不写入长期存储 | 凭据一次性、7 天有效 |
| A6 | 语言默认英语（负责人 2026-11-05），不跟随设备语言；用户的选择记在本机 | 负责人决定 |
| A7 | 所有时间按泰国时间（UTC+7）显示 | 与计量的自然月一致 |
| A8 | 只显示本人有权限的操作：没有对应权限点的按钮不显示，而不是点击后报错（负责人 2026-11-05 同意） | 减少无效操作 |
| A9 | 套餐页显示档位、每月扫描次数、成员人数上限与价格（D6）；提交申请前先弹确认框，提交后提示"申请已收到，我们会尽快联系您" | 沿用旧版文案 |
| A12 | 价格以泰铢显示，带千位分隔符，不显示货币以外的税费说明；后端金额保存到分（两位小数） | NFR-I18N-004 默认 THB |
| A10 | 品牌素材（SaiFlow 标志、品牌等待动画、"Powered by" 标志）沿用旧版 `legacy/apps/line-mini/src/assets`（负责人 2026-11-05 同意，D8） | 旧版已经过演示 |
| A11 | 通知的文字由前端按通知类型、节点与数据组成，三种语言各一套 | 后端只存类型与数据（B-2d A7） |
