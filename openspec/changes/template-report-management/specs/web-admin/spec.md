# web-admin Spec Delta

## ADDED Requirements

### Requirement: FR-SYS-142 admin 模板配置管理页面
admin 后台 SHALL 提供系统/个人/组织模板列表及配置管理，明确目标归属，复用统一逐行/逐列编辑、保存/生效、历史版本只读、JSON 导出、停用/恢复及保护删除；SHALL 提供“从样例导入”入口：选择目标（系统或客户租户）并上传 PDF/图片后进入样例页，显示进度/重试/取消/删除，READY 后原件与候选并排（原件固定可见），可改目标后保存为草稿；SHALL 列出本 admin 的近期样例；SHALL NOT 显示导入 JSON 按钮。系统模板授权 SHALL 提供精确套餐多选或查询用户/组织多选，不递归高档、不扩散点名用户到组织；SHALL 显示校验/409/引用保护，中文/英文完整。跨租户管理 SHALL 不提供客户原件/载荷/业务值；admin 样例只读自己上传的文件，由平台承担，不扣客户配额（FR-TEMPLATE-014）。

#### Scenario: AC-FR-SYS-142-01 两授权模式与编辑
- **GIVEN** 平台 admin 创建系统模板
- **WHEN** 选择 starter/intermediate，或切点名用户/组织模式，编辑结构后保存并生效
- **THEN** 两模式互斥且选择精确，界面显示草稿与生效版本分离；使用授权不授予客户修改系统模板的权利

#### Scenario: AC-FR-SYS-142-02 管理客户配置不访问业务
- **GIVEN** admin 选择某个人/组织模板配置
- **WHEN** 修改/生效、停用/删除或请求客户原件与 OCR 结果
- **THEN** 配置操作按版本和引用保护执行，业务数据请求拒绝；不能用管理员配置身份读取客户样例业务值

#### Scenario: AC-FR-SYS-142-03 从样例导入及错误反馈
- **GIVEN** admin 选择目标后上传样例，候选 code 与目标范围已有模板冲突
- **WHEN** 等待 READY，对照原件编辑并保存草稿，再手改 code 保存
- **THEN** 首次 409 提示手改副本且输入保留，不覆盖既有模板；改后创建该目标的草稿，带未确认建议且未生效；页面无导入 JSON 按钮

### Requirement: FR-SYS-143 admin 组织报表配置管理页面
admin 后台 SHALL 可选组织管理其报表配置，提供设计/保存/发布/撤销发布/删除、显式模板版本及样式/布局配置；SHALL 服从 reporting 配置合法性及并发/容量约束，不因跨租户管理授予真实统计或 CSV。效果预览 SHALL 仅用标识清晰的合成数据，不加载客户业务 JSON；真实数据相关混合单位/负值校验 SHALL 留在客户有权查询阶段。中文/英文操作与错误完整。

#### Scenario: AC-FR-SYS-143-01 合成预览与真实统计隔离
- **GIVEN** 平台 admin 设计 O 的报表
- **WHEN** 保存/发布合法配置、查看效果预览，并直接请求真实统计/CSV
- **THEN** 配置操作可完成且效果使用明确合成数据，真实统计/CSV 被拒绝；不产生客户数据查询来验证视觉效果

#### Scenario: AC-FR-SYS-143-02 无效发布与并发
- **GIVEN** O 已有有效发布 P1，admin 新草稿缺字段或基于过期修订
- **WHEN** 保存/发布/撤销/删除
- **THEN** 不完整草稿可存但发布拒绝，旧发布保留；过期修订 409 不覆盖新配置，错误按图表定位
