# line-mini Spec Delta

## MODIFIED Requirements

### Requirement: FR-SYS-056 底部导航
主界面 SHALL 有依次为“首页”“历史”“报表”“我的”的底部导航；“报表”仅在当前租户为组织、有有效 Starter 或更高订阅且用户有“报表查看”（owner 全权限）时显示，否则不显示且其余依次排列；条件随租户/订阅/权限变化在下次加载租户与用量时更新。“首页”SHALL 显示用量卡片/通知、扫描入口（FR-SYS-057）及本人待处理（FR-SYS-058），“历史”SHALL 显示 FR-SYS-108 历史。“报表”SHALL 显示有权已发布报表列表和单列详情（reporting），提供手动刷新及有导出权限的 CSV，加载/空/错误可区分，不再显示“即将推出”，不提供设计器。

#### Scenario: AC-FR-SYS-056-01 个人租户没有报表
- **GIVEN** 已登录用户的当前租户是个人租户
- **WHEN** 查看底部导航
- **THEN** 只显示"首页""历史""我的"

#### Scenario: AC-FR-SYS-056-02 Starter 起且有权限时显示报表
- **GIVEN** 当前租户是组织 O，订阅有效的 Starter，用户的角色持有"报表查看"
- **WHEN** 查看底部导航并打开报表
- **THEN** 显示"首页""历史""报表""我的"；报表页显示有权的已发布列表，详情按发布配置一行一图，不再占位

#### Scenario: AC-FR-SYS-056-03 没有权限或没有有效订阅时不显示
- **GIVEN** 当前租户是组织 O，用户的角色不含"报表查看"；或 O 的订阅已到期
- **WHEN** 查看底部导航
- **THEN** 不显示"报表"

#### Scenario: AC-FR-SYS-056-04 游客
- **GIVEN** 游客
- **WHEN** 查看底部导航
- **THEN** 只显示"首页""历史""我的"

#### Scenario: AC-FR-SYS-056-05 首页扫描入口与历史
- **GIVEN** 游客或已登录用户
- **WHEN** 打开首页并切换到"历史"
- **THEN** 首页的扫描入口可以点击，不再显示"即将推出"；"历史"显示历史列表

#### Scenario: AC-FR-SYS-056-06 租户变化及单列刷新
- **GIVEN** 用户打开 O 的报表，随后切换到 P；O/P 均有有效订阅及 report_view
- **WHEN** 加载新租户与用量并打开/手动刷新报表
- **THEN** 列表及统计只来自 P，清除 O 数据；PC y/x 顺序单列显示，不自动刷新；CSV 仍检查 export，无报表时显示空状态
